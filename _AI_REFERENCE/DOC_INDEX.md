# Documentation locale pour IA / Codex

**Description du projet :**
Jeu d'exploration / horreur type Backrooms-like, développé sur Unreal Engine. Le projet s'adresse à un développeur débutant, avec une forte focalisation sur la programmation via Blueprints.
